# Agent Date Night

Build an agentic dating web application meeting all requirements from the three-hour challenge:
1. 25 Real People: Pre-loaded roster of 25 real public individuals across tech, design, creators, and media, each with real public LinkedIn and Instagram links, high-res avatar photos, and full psychological profile cards (needs, hobbies, interests, attachment style, quirks, and dealbreakers).
2. Public Link Ingestion: An interactive "Add Candidate" drawer where evaluators can paste any pair of public links (LinkedIn + Instagram) to analyze and birth a new dating agent.
3. The Date Theater: A live, animated dating simulation between any selected pair of agents. Features atmospheric venue backdrops, turn-by-turn conversational banter, an expandable "Agent Brain" / inner monologue showing private strategic thoughts vs. spoken dialogue, and a dynamic real-time chemistry meter with post-date debrief and verdict.
4. Compatibility Matrix & Rankings: Comprehensive leaderboards showing for each person who fits them best based on intellectual synergy, lifestyle vibe, and simulated date chemistry.
5. Challenge Submission Kit: An accessible section displaying the required 200-character summary, the technical scraping architecture explanation, and a 3-minute video recording storyboard.
